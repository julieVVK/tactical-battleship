# Battleships: простой пример игры

Это отдельное рабочее дерево для ручного разбора и переноса решений в основной проект.
За основу взят backend из `main`. Расстановка и поле используют оформление `Gosha`,
роутер и диалоги главной страницы взяты из `yullia` и подключены к API.

## Запуск

Из папки `simple-game-example`, в первом терминале:

```sh
npm --prefix server install
PORT=3201 npm --prefix server start
```

Во втором терминале:

```sh
npm --prefix client install
API_TARGET=http://127.0.0.1:3201 npm --prefix client run dev -- --host 127.0.0.1 --port 5201 --strictPort
```

Открыть http://localhost:5201. Для второго игрока открыть этот же адрес в другом
профиле браузера или в приватном окне. Две обычные вкладки используют одну сессию.

## Где находится логика

- `server/games.js` хранит игры, обрабатывает ходы, готовность, выход и ходы компьютера.
- `server/gadgets.js` содержит сканирование, мину и перемещение корабля.
- `server/placement.js` проверяет расстановку.
- `server/routes/gameRoutes.js` принимает действия через HTTP и отправляет состояние через Socket.IO.
- `server/routes/userRoutes.js` завершает активные игры при выходе из аккаунта.
- `client/src/App.jsx` хранит сессию, игру, черновик расстановки и сокет над маршрутами.
- `client/src/gameApi.js` отправляет запросы на сервер.
- `client/src/board.js` содержит операции с полем.
- `MainPage.jsx` показывает диалоги создания и входа в лобби.
- `BattleshipGetReady.jsx` отвечает за расстановку, `BattleshipGame.jsx` за бой.

## Поведение

В расстановке корабль перемещается только при удержании и перетаскивании.
`R` поворачивает его во время перетаскивания, `Escape` отменяет движение.
Обычный клик ничего не поднимает. Недопустимое перемещение оставляет корабль на прежнем месте.

Каждый гаджет можно использовать один раз за матч в свой ход, после него можно стрелять.
Сканирование показывает неповрежденные клетки кораблей в выбранном квадрате 3×3.
Это снимок расположения на момент сканирования. Мина ставится на свободную клетку
своего поля и при попадании повреждает случайную целую клетку противника.
Перемещать можно только неповрежденный корабль.

Вода вокруг уничтоженного корабля отмечается автоматически. Стрелять в эти клетки
или перемещать туда корабль нельзя.

`Home` открывает меню, сохраняя участие в игре. `Resume game` возвращает к ней.
`Leave lobby` закрывает подготовку для обоих игроков. `Surrender` и выход из аккаунта
во время боя завершают матч победой соперника. Выход из аккаунта во время подготовки
закрывает лобби.

## Ограничения примера

Игры и сессии хранятся в памяти сервера и исчезают после его перезапуска.
Черновик расстановки сохраняется при переходах между страницами, но до нажатия
`Ready to go` не сохраняется при перезагрузке страницы. Отправленная расстановка
и начатый бой восстанавливаются с сервера.

У компьютера фиксированный флот и случайные выстрелы. Статистика остается учебной
заглушкой. Настройки аккаунта и другие незавершенные части основного проекта
не расширялись.
